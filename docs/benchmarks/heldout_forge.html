    num_to_index = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in num_to_index:
            return (num_to_index[complement], i)
        num_to_index[num] = i
    return None

h_know_stack_queuePrompt: What is the difference between a stack and a queue?
Check: LIFO vs FIFO
Tools: -
Answer:
A stack and a queue are both abstract data types used for storing and retrieving data, but they differ in their order of operations:

1. **Stack**: 
   - A stack follows the **Last-In, First-Out (LIFO)** principle. 
   - The last element added to the stack is the first one to be removed.
   - Think of a stack as a stack of plates; you add a plate on top and remove it from the top.

2. **Queue**: 
   - A queue follows the **First-In, First-Out (FIFO)** principle.
   - The first element added to the queue is the first one to be removed.
   - Think of a queue as a line of people waiting for a bus; the person who arrived first gets on the bus first.

In summary, a stack is like a pile of items where you add and remove from the top, while a queue is like a line of people where you add and remove from the front.
